# 📚 BIBLIOTHÈQUE DE PROMPTS PRÊTS À L'EMPLOI

Voici une sélection de prompts ultra-optimisés à copier-coller pour demander à Antigravity, Codex ou Claude de générer des interfaces d'exception.

---

### 1. Dashboard SaaS & IA (ex: AutoCall)
```text
Agis en tant que Lead Frontend Designer. Conçois le Dashboard principal de AutoCall en Next.js (App Router), Tailwind CSS et TypeScript.
Consulte les compétences de UX.UI-21ST-MCP pour :
1. Sélectionner un style 'Executive Analytics / Bento Grid' avec une palette Slate/Indigo/Emerald.
2. Intégrer :
   - Un en-tête épuré avec sélecteur de période et statut du système en temps réel.
   - 4 cartes KPI principales (Total Appels, Taux de Décroché, Durée Moyenne, Conversion IA) avec micro-graphiques de tendance sparkline.
   - Un graphique d'évolution du volume horaire.
   - Un tableau des 10 derniers appels avec lecteur audio intégré, badge de sentiment (Positif, Neutre, Urgent) et bouton d'action.
3. Applique STRICTEMENT les 5 lois Anti-Slop (zéro emoji, icônes Lucide SVG pures, responsive mobile-first, micro-ombres discrètes).
```

---

### 2. Page de Tarification & Plans (Pricing Table)
```text
Crée une section Tarification (Pricing) moderne et engageante pour notre plateforme SaaS.
1. Utilise les composants de 21st.dev MCP pour structurer une table de 3 offres (Starter, Pro, Enterprise) avec un commutateur Mensuel / Annuel (avec badge "-20%").
2. Met en valeur l'offre Pro avec une bordure subtile illuminée (Glow border) et un badge "Recommandé".
3. Liste les fonctionnalités avec des coches vectorielles SVG vertes fines.
4. Ajoute une zone FAQ en accordéon en dessous et une ligne sobre de réassurance de paiement sécurisé SSL.
```

---

### 3. Tunnel de Commande & Paiement E-Commerce (ex: DivinExpress)
```text
Refais l'interface du Checkout / Tunnel de commande.
1. Applique le style 'Stripe Minimalist Checkout'.
2. Sur mobile (< 768px), empile tous les champs verticalement sans collision. Les champs Date et CVC doivent rester sur une ligne parfaitement espacée (50/50).
3. Champs tactiles h-11, coins rounded-xl, placeholders en français soigné en casse standard (ex: "Numéro de carte").
4. Aucune alerte criarde : insère une ligne discrète avec cadenas vectoriel "Transaction chiffrée SSL 256-bit certifiée PCI-DSS".
```

---

### 4. Barre de Navigation (Navbar) & Menu Mobile
```text
Génère une barre de navigation flottante (Floating Glassmorphism Navbar).
1. Fond blanc translucide avec flou d'arrière-plan (bg-white/80 backdrop-blur-md border border-gray-200/80 dark:bg-zinc-900/80 dark:border-white/10).
2. Liens de navigation nets, logo vectoriel à gauche, boutons "Connexion" et "Essai Gratuit" à droite.
3. Menu mobile fluide avec ouverture animée sans saccade.
```
